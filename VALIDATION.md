- Production web и TypeScript собраны вместе с IPA. Версия iOS 0.3.0; arm64, iOS 15+, `com.voodeex.bodytrain`. ZIP, Info.plist и совпадение web-ресурсов проверены; тестовый код исключён.
- Браузерная проверка выполнена в отдельной локальной копии на порту 5174, с синтетическими измерениями; основной дневник на 5173 не заменялся.
- В интерфейсе: неделя 0 кг, месяц −3 кг, полгода −6 кг; реальные даты и график с расстоянием по времени. Применение −100 ккал поменяло норму 2312 → 2212 ккал, Б/Ж сохранены, углеводы 293 → 268 г. После перезагрузки норма 2212 ккал восстановилась в разделе питания; следующая оценка указана на 27 октября.

- Повторная регистрация BodyVision устранена: Vision и Keychain используют один экземпляр плагина.
- Нативный самотест 0.3.0: **7 проверок прошли**, классификация Apple Vision пропущена в симуляторе. Keychain обоих сервисов, запись JSON и восстановление store проверены после изменения регистрации плагина; самотест использовал отдельный bundle ID.
- Обычная сборка 0.3.0 установлена и запущена в iPhone 17 Pro Simulator с сохранением основного дневника. [Снимок запуска](build/verification/ios-simulator.png). Интерактивные сценарии новой функции проверены в браузере; отдельный прогон этих сценариев на физическом iPhone не выполнялся.

## Что требует внешней проверки

- IPA **не подписан**: установка на физический iPhone требует своей подписи. Установка на устройство и публикация в App Store/TestFlight не выполнялись.
- Классификация реальной еды Apple Vision и живой сканер камерой требуют физического iPhone; в симуляторе доступность сканера false, классификация явно пропущена.
- Реальные вызовы Groq/Cloudflare для анализа фото не выполнялись без личных ключей; проверены HTTP-контракт и обработка ответов/ошибок с тестовыми ответами. КБЖУ и масса по фото остаются оценкой.
- Скачивание JSON и автоматическое копирование в буфер из встроенного браузера не подтверждены. Текст JSON действительно сформирован, сохранён при проверке в файл и восстановлен через импорт. На iOS экспорт использует Filesystem Documents; эта кнопка отдельно на физическом iPhone не проверялась.

- Миграция старых настроек на Groq; старые записи питания Gemini остаются читаемыми.
- 20 тестов: дополнительно контракты обоих API, ошибки квоты/авторизации, неверный Account ID, проверка ключей без отправки фото, JSON-блоки и обрезанные ответы.
- Нативный самотест снова прошёл: ключи Groq и Cloudflare сохраняются независимо в Keychain, удаление одного не затрагивает другой.
- Оба API отвечают через dev-прокси: без ключа Groq возвращает 401, Cloudflare 400. Это проверка транспорта, а не успешного анализа фото.
- В интерфейсе проверены переключение сервисов и ошибка неверного Account ID; console ошибок не содержит. [Новые настройки](build/verification/ai-settings.jpg).
- IPA пересобран, версия 0.2.1 и совпадение всех web-ресурсов проверены; в production-коде отсутствует endpoint Google.
